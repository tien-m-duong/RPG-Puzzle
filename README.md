# Introduction
- This is a group project planned to build a Match-Three Puzzle Game with RPG elements such as boss, health, level up, etc.. 
- The project is built using Unity Game Engine

# How to run:
- Download the repository and unzip the folders
- From Unity Engine, open the folder. Every other file will be generated from Unity

# Sources:
